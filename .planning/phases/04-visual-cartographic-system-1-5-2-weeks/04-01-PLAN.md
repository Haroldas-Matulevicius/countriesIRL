<objective>
**This is the phase tracer.** It wires ONE creator-visible path through EVERY layer Phase 4 will
modify — chrome (a new rail tool and flyout) -> composition state -> a new serialized SVG layer ->
the owned export clone -> sampled PNG pixels — and proves it with a real downloaded PNG before any
other plan expands on it.

The capability: **a creator picks a water colour in a new `Map style` tool and the exported PNG's
ocean is that colour.**

Purpose: retire the phase's single highest-fidelity risk in wave 1. `04-RESEARCH.md § Export
Fidelity Envelope` measured that a serialised SVG rasterised as an image sees **no host stylesheet** —
a host `var()` renders as nothing and a host class rule renders as SVG default black. `--map-surface`
therefore contributes **zero pixels** to the PNG today. If the serialized-layer approach did not
survive this repo's own `sanitizeExportClone` / `isPreservedComposition` path, every later plan in
this phase would be built on a dead architecture. Proving it now costs one commit; discovering it at
`04-15` costs ten.

This tracer is **production-quality, not a prototype**. Everything it lands stays: the contrast
module, the water preset table, the surface rect, the rail row, the panel shell, and the PNG gate.
Later plans expand out from it (uncolored fill and borders in `04-08`, bands in `04-10`, text in
`04-11`), they do not replace it.

Output: `src/utils/contrast.ts`, `src/constants/mapStyle.ts`, `DropletIcon`, `MapStylePanel`,
`src/styles/controls/mapStyle.css`, a `rect[data-layer="surface"]` in the composition layer, an

</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| creator keyboard -> composition state | The custom `#RRGGBB` entry is untrusted text that becomes an SVG attribute value. |
| composition state -> serialized SVG -> rasteriser | The clone is serialized to a data URL and loaded as an isolated document. |
| bundled asset -> app | Same-origin `public/data/` only. No network at runtime. |

**Calibration, stated plainly:** CountriesIRL is **browser-only and localhost-only**. There is no
backend, no auth, no session, no secret, no deployment target, and no runtime third-party request.
ASVS V2 (Authentication), V3 (Session), and V4 (Access Control) are **not applicable — no such
surface exists**, and inventing a server-side threat here would be worse than recording none.
