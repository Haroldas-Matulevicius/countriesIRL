<objective>
Persist everything Phase 4 added, migrate V2 records in memory to a single rendering path, and finally
exercise carry-forward **`G-2`**.

Purpose: D4-17 chooses **one rendering path with no legacy mode**, knowingly. A saved map will look
genuinely different when reopened, and its exported PNG will differ from one the creator has already
posted. That is accepted because the alternative is keeping the legend chrome D4-11 deleted **plus** a
parallel legacy renderer with its own gates — the two-models-coexisting complexity that produced the
`G-3` complaint in the first place.

D4-18 folds in `G-2` because the V3 migration suite already constructs stored records directly, which
is the cheapest possible way to cover it. **`G-2` has never been exercised by human or machine** — the
owner had no pre-restyle saved map with a 15-32 character label, and no automated test covers it either.

Output: a V3 branch beside the V2 one, extended bounds in the existing order, a round-trip gate with a
discrimination control, and a G-2 test bound to behaviour rather than to a constant.
</objective>

failure mode that matters: a field that is **written but not read back** round-trips as

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| **`localStorage` -> `inspectStoredRecord`** | **The single largest untrusted-input surface in the app.** A hand-crafted record is fully attacker-controlled JSON. |
| composition state -> `save()` -> `localStorage` | Serialisation of creator content, including free text from `04-11`. |

**Calibration, stated plainly:** browser-only, localhost-only. No backend, no auth, no session, no
secrets, no network. There is no remote attacker — reaching this surface requires editing
`localStorage` by hand on the same machine. That does **not** make the bounds decorative: they are the
existing defence and this plan widens exactly what they parse, which is why the register below is the
longest in the phase. ASVS V2/V3/V4 are **not applicable — no such surface exists.** Applicable:
**V5 (Input Validation)** above all.
