<objective>
Build the reference-style frame once, end to end, and inspect the bytes.

Purpose: `04-CONTEXT.md` D4-14 is explicit that **even the integration plan asserts properties, not a
baseline image.** Five of the phase's plans move exported pixels. Each asserts only the property it
owns, so a later plan cannot redden an earlier plan's gate — and this plan is where that design claim
gets tested, by running all of them against one composite frame in one run.

The frame to build is the owner's reference, as characterised in `04-CONTEXT.md § specifics`: white
water, flat mid-grey out-of-scope land, thin dark borders between countries with coastlines doing no
work, a legend on the left edge below the title block with no container, small near-black type, and no
visible bands on white.

Output: one integration spec, a recorded set of measured numbers, and evidence that the phase's gates
are mutually independent.
</objective>

every `expect` a message saying what its failure means:

- **Water** — an ocean sample equals the chosen surface colour (04-01).
- **Uncoloured fill** — an uncoloured country's interior equals `settings.uncoloredFill` and differs
  from the water (04-08).
- **Ramp fills** — two countries painted at different steps have **different** interior colours, and
  each matches its shade from `RAMPS` (04-02 / 04-05).
- **Quiet coastline, present interior border** — a coastline sample carries no dark ink while an inland
  border sample does, in this one export (04-08 / 04-09).
- **Band** — the three-sample luminance ordering along the band axis. ⚠ **On white water the band is
  invisible by design.** Either set a non-white surface for the band assertions or use a sample column
  crossing dark land — **state which, in the spec's comment and in the SUMMARY.** A white-on-white
  sample measures nothing and passes (04-10).
- **Title** — ink in a disjoint title region (04-11).
- **Legend** — ink inside a region **derived from `resolveLegendRender`**, and none inside the top
  band's extent (04-12 / 04-13).

**Discrimination controls, non-negotiable.** Reuse 02-27's blank export in the **same run**, run it
through the **same** counting machinery, and assert it reads zero ink and differs from the real frame.
Assert a **content floor first** on every crop before any inequality — two blank crops satisfy "they
differ" perfectly, and that exact defect has shipped in this repository once. Count colours in
**disjoint regions**, never across the whole frame.

**No whole-image baseline.** Do not add a snapshot image, do not add a pixel-diff comparison against a
stored PNG, and do not introduce a visual-regression helper. A re-baseline diff can never be
RED-provable on its own subject.

Record every measured value — each sample's RGB, each ink count, each threshold and how it was derived —
in the SUMMARY as numbers. Thresholds come from these measurements, never from a guess.

**RED-proof the composite on its own subject, as a required step.** Replace the built frame with the
blank export and confirm that **each** of the seven property assertions goes red — not just one. If any
single assertion survives a blank frame, that assertion has no content floor and must be fixed before
this task is done. Record which assertions reddened and, if any did not, **say so plainly instead of
claiming the gate passes.**
