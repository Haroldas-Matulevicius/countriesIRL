fill.

**What the reference actually does**, characterised in `04-CONTEXT.md § specifics`: a **stacked colour
bar** — contiguous swatches, no gaps between them, short tick leaders to the right — where the numbers
are **break boundaries** (10.5 / 9.0 / 8.0 / 6.0 / 5.0 / 4.0 / 3.0) read *between* ticks, never printed
as literal range text. One bold caption line above it. No container of any kind.

be made just as subtle, user should be able to pick - well it should be default based on what color
technique used tbh too."* So Rows is not left alone — it is **restyled to match the bar**.

Purpose: this is what makes the palette read as cartographic rather than as a colour picker. The ramp
strip in the Colors panel was deliberately built to **visually rhyme** with this bar — same idiom, one
in chrome tokens and one in composition ink.

Output: a second layout function, a form dispatch, a restyled Rows form, a bound "no data" row, the
CD-8 roadmap amendment, and the owner checkpoint that finally answers `G-1`.
