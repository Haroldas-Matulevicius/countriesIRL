<objective>
Take ownership of the SVG→PNG export path. Remove `html2canvas`, rasterise the frozen clone
directly, and build a **generalised** inline font-embedding seam so the legend can finally export
in the typeface it already names.

Purpose: the whole composition is a single SVG, and `html2canvas@1.4.1` never descends into an
`<svg>` — it serialises it with `XMLSerializer` into a `data:image/svg+xml` URL and rasterises it
as an `<img>`. That image is an isolated document with no host stylesheets and no ability to issue
a request. This is why `LegendOverlay.tsx:167` names Inter while the repo has **zero**
`@font-face` rules: **the legend already exports in a system fallback today.** The dependency is
~200KB doing a job we can do directly, in the one way that also fixes the font.

`src/utils/export.ts` is the most safety-critical file in the repository and this is Phase 3's
largest single risk. Every non-negotiable is carried verbatim and RED-proven against the **new**
path, not observed green and assumed.

Output: a rewritten rasterisation path, `src/styles/interFontFace.ts`, legend typography, and
assertion 25 measuring pixels rather than markup.
</objective>
